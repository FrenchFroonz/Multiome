## Upcoming Downstream Scripts Roadmap

### Script 03: `03_Transcription_Factor_Motif_Analysis.Rmd`
* **Agent Skill:** `bio-atac-seq-motif-deviation`
* **Objective:** Quantify transcription factor (TF) activity dynamics across Ganglioglioma cell types.
* **Key Tasks:**
  1. Add positional frequency matrices (PFM) from the **JASPAR2024** database (vertebrate collection) using `Signac::AddMotifs()`.
  2. Run **chromVAR** to calculate GC-bias corrected motif deviation scores across single cells.
  3. Identify differentially active transcription factors (e.g., AP-1 family, SOX family, OLIG2, proneural TFs) between tumor and normal glial/neuronal cells.
  4. Visualize motif activities using UMAP projections and heatmap cluster profiles.

---

### Script 04: `04_Peak_to_Gene_Enhancer_Linking.Rmd`
* **Agent Skill:** `bio-atac-seq-enhancer-gene-linking`
* **Objective:** Discover putative cis-regulatory elements (enhancers/promoters) governing gene expression in Ganglioglioma.
* **Key Tasks:**
  1. Pair single-cell chromatin accessibility in MACS2 peaks with single-cell gene expression using Signac's `LinkPeaks()`.
  2. Compute distance-dependent correlation between peak accessibility and target gene expression within a $\pm 500\text{ kb}$ genomic window.
  3. Validate linked regulatory elements against known brain and ENCODE cCRE annotations (`encode-ccres-database`).
  4. Generate locus coverage plots (`CoveragePlot()`) visualizing chromatin tracks, co-accessibility links, and gene annotations at key Ganglioglioma oncogenic loci (e.g., *BRAF*, *CDKN2A*, *MAPK* pathway members).

---

### Script 05: `05_Pseudobulk_Differential_Accessibility.Rmd`
* **Agent Skill:** `bio-atac-seq-differential-accessibility`
* **Objective:** Statistically identify differentially accessible chromatin regions (DARs) between neoplastic cells and non-malignant brain cells.
* **Key Tasks:**
  1. Aggregate single-cell fragment counts into pseudobulk replicate profiles per cell type / condition to account for biological variability.
  2. Perform rigorous statistical testing using **DESeq2** or **edgeR** with appropriate dispersion estimation.
  3. Annotate DARs as promoter-proximal, intronic, or distal intergenic enhancers using `ChIPseeker` or `GenomicFeatures`.
  4. Perform functional enrichment of DARs using Reactome / Gene Ontology pathways (`reactome-database`, `quickgo-database`).

---

### Script 06: `06_TF_Footprinting.Rmd` (Optional / Advanced)
* **Agent Skill:** `bio-atac-seq-footprinting`
* **Objective:** Confirm direct physical transcription factor binding at base-pair resolution within candidate enhancers.
* **Key Tasks:**
  1. Profile Tn5 cut-site depletion ("footprints") directly over motif centers for key candidate TFs identified in Script 03.
  2. Compare footprint depth between tumor cells and non-neoplastic controls using `Footprint()` and `PlotFootprint()` in Signac.
